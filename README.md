# customer-personality-analysis

Анализ эффективности маркетинговых кампаний и поведения клиентов на основе открытого датасета Customer Personality Analysis. В проекте были использованы Python (pandas) для очистки данных и SQL для написания аналитических запросов. Проект отвечает на 4 вопроса.

## Вопросы

1. Какие сегменты клиентов (по семейному положению, возрасту, доходу) откликаются на рекламные предложения чаще?
2. Какая из пяти маркетинговых кампаний была самой эффективной?
3. Как влияет наличие детей в семье на траты клиента?
4. Какая связь между возрастом учетной записи клиента и его тратами?

## Данные

Датасет Customer Personality Analysis: https://www.kaggle.com/datasets/imakash3011/customer-personality-analysis

2240 записей, 29 столбцов:
- Данные клиентов (возраст, доход, семейное положение, кол-во детей);
- Затраты по категориям товаров;
- Отклик на каждое из пяти рекламных предложений.

## Инструменты

- **Python** (pandas) - загрузка, форматирование и выгрузка очищенных данных
- **SQL** (SQLite) - аналитические запросы
- **Power BI** - визуализация результатов

## Процесс работы

1. Загружены и осмотрены исходные данные ('.info()', '.dtypes', '.describe()')
2. Очищены данные (неверный возраст, пропуски в доходах, удалены не представляющие интереса колонки)
3. Выгружены очищенные данные в файл marketing.db
4. Проведен анализ по 4 вопросам при помощи SQLite
5. Визуализированы результаты в Power BI

## Результаты анализа

**Сегменты и отклик на кампании**
- Одинокие клиенты откликаются почти вдвое чаще, чем находящиеся в паре (20,8% - 23,7% против 10,5% - 11,4%)
- Клиенты возрастом 30-45 лет наиболее отзывчивы
- Клиенты в верхнем квартиле дохода имеют наибольший отклик - 26,9%

**Эффективность кампаний**
- Кампании 3, 4, 5 показали схожий результат отклика (7,2% - 7,4%), кампания 1 имеет 6,4% откликов, кампания 2 сработала заметно хуже - 1,4% откликов.

**Траты в зависимости от кол-ва детей**
- Явная тенденция: больше детей - меньше трат. У клиентов без детей траты вдвое больше, чем у клиентов с 1 ребенком.

**Траты в зависимости от возраста учетной записи**
- Чем дольше клиент зарегистрирован - тем выше средние траты
